# Tool Usage & Runbook

Purpose
- Quick reference for running the project, tests, migrations, and common developer tools.

Prerequisites
- Node.js (LTS), npm
- Docker (for Postgres), Docker Compose
- Copy `.env.example` → `.env` and set DB credentials

Common commands
- Start Postgres (docker-compose):
  ```bash
  docker compose up -d
  ```
- Install dependencies:
  ```bash
  npm install
  ```
- Generate Prisma client:
  ```bash
  npx prisma generate
  ```
- Apply migrations (development):
  ```bash
  npx prisma migrate dev --name <name>
  ```
- Run dev server (auto-reload):
  ```bash
  npm run dev
  ```
- Run lint/format (if configured):
  ```bash
  npm run lint
  npm run format
  ```

Notes for automated agents
- Ensure Postgres is available and `.env` is present before starting the app.
- When proposing schema changes, include a migration, `prisma generate`, and a short rollback plan.
- Avoid modifying migrations generated by others; add new migrations for changes.
